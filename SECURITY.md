# Security policy

## Supported versions

Security fixes target the newest tagged release. Older releases and untagged
source snapshots do not receive separate maintenance.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability-reporting form](https://github.com/yaugenst/advect/security/advisories/new)
so the report, impact, reproduction details, and disclosure timeline remain
private while they are assessed.
