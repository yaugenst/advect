# Security policy

## Supported versions

Advect is pre-1.0 software. Security fixes are made for the newest tagged
release; older releases and untagged source snapshots do not receive a separate
maintenance promise.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability-reporting form](https://github.com/yaugenst/advect/security/advisories/new)
so the report, impact, reproduction details, and proposed disclosure timeline
remain private while they are assessed.

The form must be enabled before the repository becomes public. If it is not
available, contact the repository owner through
[the maintainer profile](https://github.com/yaugenst) and request a private
reporting channel without including vulnerability details in the initial
message.
