NumPy¶

NumPy is Advect's first-class frontend, intercepted through NumPy's own protocols (__array_ufunc__, __array_function__, and constructor like= dispatch). The qualified range is NumPy 2.0 to 2.4. NumPy declares the Array API revision implemented by the installed release:

  • installed NumPy 2.4.6: Array API 2024.12

The mode columns are public support claims: yes means the callable's declared contract is supported end to end in that execution mode (dynamic tracing, abstract staging, serialized artifacts). Restricted implementation paths may remain internal, but registration alone does not promote an additional upstream spelling into this catalog.

Abstract=yes means that a primitive has a standalone abstract rule. A frontend may still be staged by an explicit method or composite lowering when its displayed primitive does not.

Rows marked Array API (163 of 393) reuse the same canonical primitive as an Array API binding. They inherit primitive semantics and derivative rules, not the Array API frontend signature.

Only supported ufunc methods are listed; 383 other method forms are unqualified. Every row is backed by an executable NumPy case for each marked lifetime. Reachable handlers without that evidence are omitted. The nine numpy.lib.scimath rows are dynamic-only because their result dtype can depend on values.

Restricted staged forms¶

Callable rows are conservative across their executable variants. numpy.round supports staging and serialization when decimals is omitted or zero; nonzero decimals is dynamic-only. numpy.linalg.eig and numpy.linalg.eigvals support all three lifetimes for complex input dtypes, while real input dtypes are dynamic-only.

numpy.linspace is dynamic-only when its endpoints are traced, including the two-output retstep=True form. NumPy accepts array-valued endpoints, whereas the shared Array API primitive has static scalar endpoint attributes, so those NumPy calls cannot be serialized. A constant-only call may be captured as a graph constant; that is not staged numpy.linspace support.
