Tutorials¶

Advect has two execution modes. Use grad directly when ordinary Python control flow and a fresh trace per call are what you want. Use stage when one shape/dtype signature will run repeatedly or when you need a serializable program.

The tutorials are built from runnable snippets. Press [ run ] under a snippet to execute it in your browser; each page is one Python session, and running a snippet first runs the ones above it.

  • Gradients and pytrees — grad, scalar inputs, traced constructors, multiple arguments, jacobian
  • Control flow and mutation — loops, in-place updates, converged solves, SciPy callbacks
  • Staging and serialization — stage, derivative programs, durable artifacts
  • Providers and interop — provider-neutral functions, Array API providers, xarray labels
  • Custom primitives — @ad.primitive and the authoring checks
  • Debugging — scoped inspection, numerical failures, staged context, and suspicious-gradient checks
