# Special Functions

Use these explicit Advect counterparts when a
[`scipy.special`](https://docs.scipy.org/doc/scipy/reference/special.html)
function must remain differentiable or stageable. See the
[Scientific Python tutorial](../../tutorials/scientific-python.md#use-the-differentiable-scipy-namespace)
for a `logsumexp` gradient and the
[compatibility table](../../compatibility/scipy.md) for exact coverage.
